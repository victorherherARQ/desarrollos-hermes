Why CIBA?

Auth Code

User must be present at the browser/app

The classic OAuth flow requires the user to be redirected to the IdP, log in, and come back. The user is actively involved in every step — they must be at a browser or app.

CIBA

User is NOT present — agent acts on their behalf

With CIBA, an AI agent initiates the authentication. The user receives a push notification on their phone, approves with biometrics, and the agent gets a token — without the user being at a browser.

Use case: AI voice agents (Hermes) that need to access user resources — calendar, email, files — while the user is on a phone call or away from their computer.
