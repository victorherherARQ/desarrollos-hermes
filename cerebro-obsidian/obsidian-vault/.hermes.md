# Cerebro Obsidian — Context File

## Objetivos
- Mantener el vault organizado y al día
- Registrar tareas, personas y temas con sus tags
- Documentar decisiones y actuaciones

## Tags del sistema

### Tareas
| Tag | Significado |
|-----|-------------|
| `#tarea` | Tarea pendiente |
| `#tarea/pendiente` | Tarea pendiente |
| `#tarea/en-progreso` | En curso |
| `#tarea/completada` | Hecha |
| `#tarea/urgente` | Prioridad alta |

### Personas
| Tag | Significado |
|-----|-------------|
| `#persona` | Ficha de persona |
| `#contacto` | Contacto profesional |
| `#equipo` | Miembro del equipo |

### Temas
| Tag | Significado |
|-----|-------------|
| `#tema` | Tema principal |
| `#nota` | Nota informativa |
| `#referencia` | Referencia |
| `#idea` | Idea |
| `#proyecto` | Proyecto |

## Estructura del vault
```
obsidian-vault/
├── Tareas/          # Tareas pendientes, completadas, próximas
├── Personas/        # Fichas de personas
├── Temas/          # Notas sobre temas
├── Proyectos/       # Fichas de proyectos
├── 00 Meta/        # Índice general
├── opencode/       # Skills para OpenCode CLI
│   ├── tareas/     # buscar, crear, completar, reporte
│   ├── personas/   # buscar, crear
│   └── temas/      # investigar, resumir
└── actuaciones/    # Historial diario (YYYY-MM-DD.md)
```

## Reglas
- Al terminar una sesión, si hay trabajo nuevo, crear/actualizar la nota de actuación en `actuaciones/YYYY-MM-DD.md`
- Usar links internos `[[nombre]]` entre notas
- Nombres de archivos: `kebab-case.md`
- Tareas con formato: descripción + proyecto + prioridad
- Personas con datos: nombre, rol, contacto, proyectos relacionados

## Comandos útiles (OpenCode)
```bash
# Buscar tareas pendientes
opencode "busca todas las notas con tag #tarea"

# Crear tarea
opencode "crea una tarea en el vault"

# Generar reporte
opencode "genera reporte de tareas"
```
