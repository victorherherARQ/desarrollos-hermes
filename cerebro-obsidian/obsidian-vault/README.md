# Obsidian Vault — Second Brain de Victor

Vault de Obsidian para gestión de tareas, personas, temas y proyectos.

## Estructura

```
obsidian-vault/
├── Tareas/           # Gestión de tareas pendientes y completadas
├── Personas/         # Fichas de personas (contactos, compañeros)
├── Temas/            # Investigación y notas sobre temas
├── Proyectos/        # Proyectos activos con documentación
├── 00 Meta/          # Índice, templates, notas diarias
└── README.md         # Este archivo
```

## Tags recomendados

| Tag | Significado |
