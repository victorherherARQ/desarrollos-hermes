# Obsidian Vault — Victor's Second Brain

Vault de Obsidian para gestión de tareas, personas, temas y proyectos.

## Estructura

```
obsidian-vault/
├── Tareas/          # Gestión de tareas pendientes y completadas
├── Personas/         # Fichas de personas (contactos, compañeros, clientes)
├── Temas/            # Investigación y notas sobre temas
├── Proyectos/       # Proyectos activos con su documentación
├── 00 Meta/         # Índice, templates, daily notes
└── README.md        # Este archivo
```

## Tags recomendados

- `#tarea` — tarea pendiente
- `#tarea/completada` — tarea hecha
- `#persona` — contacto
- `#proyecto` — proyecto activo
- `#nota` — nota general
- `#referencia` — información de referencia
