# Completar Tarea

## Prompt para opencode

1. Mueve la nota de tarea de `Tareas/Pendientes/` a `Tareas/Completadas/`
2. Cambia `#tarea` por `#tarea/completada`
3. Añade fecha de completado
4. Registra en `Tareas/Completadas.md` con enlace a la nota

## Ejemplo

```
opencode "Completa la tarea de actualizar docs del agentgateway"
```
