# Generar Reporte de Tareas

## Prompt para opencode

Genera un reporte de tareas del vault de Obsidian.
Incluye:
1. Tareas urgentes
2. Tareas por proyecto
3. Tareas sin proyecto
4. Tareas completadas esta semana
5. Resumen general

Formato: markdown listo para enviar por Telegram.

## Ejemplo

```
opencode "Genera reporte de tareas de esta semana"
```
