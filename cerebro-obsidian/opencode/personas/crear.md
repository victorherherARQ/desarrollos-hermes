# Crear Ficha de Persona

## Prompt para opencode

Crea una nueva nota de persona en el vault de Obsidian.
Usa el template:

```markdown
# [Nombre]

## Datos
- **Nombre**: 
- **Rol**: 
- **Ubicación**: 
- **Contacto**: 
- **Telegram**: 
- **Email**: 

## Tags
#persona #contacto

## Proyectos


## Notas
-
```

Guarda en: `obsidian-vault/Personas/[Nombre].md`

## Ejemplo

```
opencode "Crea ficha de persona para María, desarrolladora frontend"
```
