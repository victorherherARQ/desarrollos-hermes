# Investigar Tema

## Prompt para opencode

Investiga sobre [TEMA] y crea una nota en el vault de Obsidian.
La nota debe incluir:
1. Definición breve
2. Conceptos clave (bullet points)
3. Casos de uso
4. Tecnologías/herramientas relacionadas
5. Recursos (links, docs)
6. Tags relevantes

Guarda en: `obsidian-vault/Temas/[Tema].md`

## Ejemplo

```
opencode "Investiga sobre k3s y crea nota en el vault"
```
