# Resumir Tema

## Prompt para opencode

Busca todas las notas relacionadas con [TEMA] en el vault.
Genera un resumen estructurado con:
1. Definición
2. Puntos clave
3. Conexiones con otros temas
4. Tareas pendientes relacionadas
5. Recursos

## Ejemplo

```
opencode "Resume todo lo que sé sobre OAuth2"
```
