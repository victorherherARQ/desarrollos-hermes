# Crear Tarea

## Prompt para opencode

Crea una nueva nota de tarea en el vault de Obsidian.
Usa el template:

```markdown
# [Título de la tarea]

## Descripción


## Proyecto
-

## Prioridad


## Fecha límite


## Tags
#tarea #pendiente

## Notas adicionales
```

Guarda en: `obsidian-vault/Tareas/Pendientes/[fecha]-[slug].md`

## Ejemplo

```
opencode "Crea tarea para revisar PR del agentgateway"
```
